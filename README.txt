# Nea IA - PWA Package

Este pacote contém todos os arquivos necessários para transformar a Nea IA em um PWA (Progressive Web App) e gerar aplicativos nativos para Android e Windows no PWABuilder!

## O que contém este arquivo ZIP:
1. `manifest.json` - Manifesto Web App exigido pelo PWABuilder.
2. `sw.js` - Service Worker para permitir funcionamento offline e instalação.
3. `icon-192.png` & `icon-512.png` - Ícones do aplicativo para tela inicial e loja.
4. `icon.svg` - Ícone vetorial do aplicativo.
5. `index.html` - Código principal da sua aplicação Nea IA.

## Como usar no PWABuilder:
1. Faça o deploy do seu site na **Vercel** ou **Netlify** enviando estes arquivos.
2. Acesse https://www.pwabuilder.com
3. Cole a URL do seu site publicado e clique em **Start**.
4. O PWABuilder analisará o site e liberará o botão **Build My PWA** para você baixar o pacote do **Android (APK/AAB)** ou **Windows (MSIX)**!
